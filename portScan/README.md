# Apresentação

Essa é uma pequena ferramenta em Python que tem como foco realizar a varredura de portas e obtenção de banners em hosts especificados pelo usuário. Abaixo segue algumas características do código
- A principal biblioteca utiliza é a biblioteca **socket**
- Faz a identificação de serviços e obtenção de banners de um host.
- Utiliza as bibliotecas **threading** e **queue** para melhor performance do código.
- Aceita entradas do usuário e realiza a validação da entrada.
- Salva os resultados em .txt e .csv
