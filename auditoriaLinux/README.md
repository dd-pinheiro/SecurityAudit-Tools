# Apresentação

Essa é uma pequena ferramenta em Python que tem a função de a auditoria de segurança utilizando comandos para reconhecimento e análise do sistema. Além disso, ele também salva o resultado em um arquivo com a data atual o qual foi realizada a análise.
- Aceita entrada de um arquivo xlsx/xls do usuário.

## Pontos de atenção
O script deve ser executado com permissões administrativas.
- O script é feito para sistemas baseado em Debian/Ubuntu e CentOS/RHEL.
- Ele não detecta automaticamente comportamentos anômalos, mas sim fornece um relatório para análise manual.
